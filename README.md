# Lodu & Sap Master (লুডু ও সাপ-লুডু রিওয়ার্ড গেম)

একটি সম্পূর্ণ মোবাইল ও ওয়েব রেসপনসিভ **লুডু ও সাপ-লুডু (Snakes & Ladders)** 2-in-1 রিওয়ার্ড গেম।

---

## 🎯 গেমের মূল নিয়মাবলি (Game Rules)
1. **লেভেল ও ম্যাচ সংখ্যা:** মোট ২০টি লেভেল। প্রতি লেভেলে ১০টি ম্যাচ (সর্বমোট ২০০ ম্যাচ)।
2. **পাস কন্ডিশন:** ১০টি ম্যাচের মধ্যে অন্তত **৮টি ম্যাচ জিততে হবে** (8/10 Wins)।
3. **ফেল কন্ডিশন:** যেকোনো লেভেলে **৩টি ম্যাচ হারলে সরাসরি Level 1 এ রিসেট** হয়ে যাবে।
4. **রিওয়ার্ড:** প্রতিটি লেভেল সফলভাবে সম্পন্ন করলে ওয়ালেটে **২০ টাকা** যোগ হবে।
5. **উইথড্রয়াল:** মিনিমাম উইথড্রয়াল লিমিট **২০০ টাকা** (বিকাশ / নগদ / রকেট)।
6. **এআই ডিফিকাল্টি:**
   - Level 1 - 2: Easy (সহজ)
   - Level 3 - 4: Medium (মাঝারি)
   - Level 5 - 6: Hard (কঠিন)
   - Level 7 - 8: Extreme Hard (চরম কঠিন)
   - Level 9 - 20: Never Won / Rigged (অসম্ভব)

## 💰 Moneytag অ্যাডভার্টাইজিং স্লট (Ad Placements)
- **In-Page Push (Banner):** স্ক্রিনের নিচে নন-অবস্ট্রুসিভ স্টিকি ব্যানার।
- **Vignette Ads (Interstitial):** প্রতি ম্যাচ শেষে ফলাফল ও ট্রানজিশনের সময় ইন্টারস্টিশিয়াল অ্যাড।
- **Rewarded Video Ads:** ৩টি ম্যাচ হারার পর প্লেয়ারের জন্য *"ভিডিও অ্যাড দেখে ১টি রিভাইভ নিন"* অপশন।

আপনার অফিসিয়াল Moneytag স্ক্রিপ্ট বসাতে `index.html`-এর `<head>` ট্যাগের ভেতরে আপনার কোড পেস্ট করুন:
```html
<script src="https://alwingulla.com/88/tag.min.js" data-zone="YOUR_ZONE_ID" async data-cfasync="false"></script>
```

## 🚀 গেমটি চালু করার নিয়ম (How to Run)
সরাসরি ব্রাউজারে চালাতে `index.html` ফাইলটিতে ডাবল ক্লিক করুন অথবা নিচের কমান্ডটি চালান:
```bash
npx serve .
```
কিংবা VS Code-এর **Live Server** দিয়ে ওপেন করতে পারেন।
